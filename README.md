# Elite Auto Tech — site institucional

Landing page estática e responsiva desenvolvida para a Elite Auto Tech Mecânica Automotiva, em Canoas/RS.

## Editar

- Conteúdo e estrutura: `index.html`
- Estilos e responsividade: `styles.css`
- Transições e menu: `script.js`
- Imagens: diretório `assets/`

Para visualizar localmente, execute um servidor HTTP simples na pasta do projeto.
